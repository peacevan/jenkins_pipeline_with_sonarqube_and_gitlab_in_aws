# Documentação

Este diretório agrupa a documentação detalhada do projeto.

Arquivos principais

- [PLANO_DE_MELHORIA.md](PLANO_DE_MELHORIA.md) — Plano de melhorias e roadmap para transformar o repositório em um case de portfólio.
- [STEP_BY_STEP.md](STEP_BY_STEP.md) — Instruções detalhadas de instalação e configuração (Jenkins, SonarQube, GitLab).
- [RESUMO.md](RESUMO.md) — Resumo rápido e pontos importantes.

Boas práticas

- Antes de compartilhar, substitua todos os placeholders (`<JENKINS_PUBLIC_IP>`, `<KEY_PAIR_FILE>`, etc.) por valores genéricos.
- Mantenha evidências (prints, diagramas) em `img/` e referencie aqui quando adicionar.

Como contribuir para a documentação

1. Crie uma branch a partir de `main` com o prefixo `docs/` ou `improve/docs/`.
2. Faça as alterações e abra um PR descrevendo as mudanças.

Histórico

Documentos movidos da raiz para organização e clareza do repositório.
